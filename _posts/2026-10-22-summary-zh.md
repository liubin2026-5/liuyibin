### [LiteLLM 1.107.0 遭供应链攻击植入窃密后门](https://safedep.io/litellm-pypi-compromise-credential-stealer-backdoor/) ⭐️ 9.0/10

据 safedep.io 报道，PyPI 上的 LiteLLM 1.107.0 版本被篡改，安装后会植入凭据窃取程序和后门。LiteLLM 是广泛使用的 Python LLM 工具库，此次事件属于严重的软件供应链安全事件，直接影响使用该库的开发者与 AI 基础设施。报道称攻击者攻陷了 3 个不同的开发者 GitHub 凭据，项目方已撤销除一名开发者外的所有相关凭据。目前尚不清楚受影响的具体范围与窃取数据的去向，建议用户避免安装 1.107.0 并检查依赖。

hackernews · abhisek · 10月21日 14:00 · [社区讨论](https://news.ycombinator.com/item?id=50181114)

**「背景」** LiteLLM 是一个用于统一调用多种大语言模型 API 的 Python 库，在 AI 应用开发中被广泛依赖。PyPI 是 Python 官方的包索引，开发者通过 pip 安装的包若被恶意篡改，可能在安装或运行时执行任意代码。这并非 LiteLLM 首次遭遇供应链攻击，社区提到约一年前也曾发生过类似事件。

**「影响」** 任何在受影响时间窗口内安装 LiteLLM 1.107.0 的开发者或 CI 环境都可能泄露云凭据、API 密钥等敏感信息，应视为已失陷并立即轮换相关凭据。

**「社区讨论」** 社区对此次事件反应强烈，有人指出这是 LiteLLM 一两年内第二次重大供应链攻击，并质疑拥有 5.5 万次提交的项目为何仍被攻破。多位评论者认为 3 名开发者凭据同时被窃表明问题具有系统性，建议将 LiteLLM 固定在此版本之前的版本，并提醒权限弹窗疲劳和盲目安装工具会削弱沙箱等防护措施的有效性。

### [整数乘法亚 O\(n log n\) 算法论文与 Lean 形式化进展](https://web.maths.unsw.edu.au/~davidharvey/research/subnlogn.pdf) ⭐️ 8.0/10

Hacker News 上出现了一篇关于近期提出的整数乘法亚 O\(n log n\) 算法的论文链接，作者为 David Harvey。讨论中，用户 jdb1729 表示该结果已由他与 @platypii 在 Mathlib 的 TM2 机器上完成 Lean 形式化，当前指数界为 1-2^-14.38，并持续改进，代码托管在 GitHub 的 integer-mult-bounds-lean 仓库。jdb1729 还指出，新结果并不直接给出固定有限域上多项式乘法的新复杂度界，该问题目前最优算法为 O\(n log n 4^log\*\(n\)\)（HvdH19），他们也为素数阶有限域上的 DFT 取得了同样的改进的 Lean 证明。讨论中有人强调标题中的关键是小写 o\(n log n\) 而非 O\(n log n\)。

hackernews · craigcitro · 10月22日 02:30 · [社区讨论](https://news.ycombinator.com/item?id=50190455)

**「背景」** 整数乘法的经典复杂度长期以 O\(n log n\) 为参照，Schönhage-Strassen 等算法达到 O\(n log n log log n\) 量级，而近年研究试图突破到严格小于 O\(n log n\) 的 o\(n log n\)。该方向涉及多篇密切相关、数学密度很高的论文，理解门槛较高。Lean 与 Mathlib 是交互式定理证明工具与数学库，可用于机器验证复杂算法分析。

**「影响」** 若形式化完成并持续改进指数界，将为这一理论结果提供机器可检验的正确性保证，但短期内对实际整数乘法实现的影响仍有限。

**「社区讨论」** 评论者普遍认为相关论文的数学阐述不够友好，有人尝试阅读后放弃，转而借助 LLM 理解并判断论证正确，同时对此感到不安。另有评论者强调应区分小写 o\(n log n\) 与大写 O\(n log n\)，并指出该结果与有限域多项式乘法的复杂度界并不直接等同。

### [浙大首发硅-28 硅烷特气与 4 英寸外延片](https://www.ithome.com/1/016/490.htm) ⭐️ 8.0/10

浙江大学杭州国际科创中心量子信息硅团队在第二届量子科技前沿论坛上，国内首次发布硅-28 硅烷特气与 4 英寸硅-28 外延片两项成果。经中国计量科学研究院检测，硅-28 硅烷特气的硅-28 同位素丰度为 99.99576%，化学纯度为 99.99998%；经二次离子质谱检测，外延层中的硅-28 丰度为 99.9937%，与特气丰度处于同一量级，表明从气源到固态外延层的转化过程未出现显著的同位素稀释。该成果属于国家级课题“量子信息硅-28 同位素外延片制备及应用”的阶段性进展，补齐了硅-28 从特气到外延片的关键两环，使国内硅基量子芯片研发在衬底材料端有了可用的国产选项。不过当前公布的是材料制备阶段的检测数据，尚未涉及以该外延片制造的量子器件在相干时间、门保真度等核心量子指标上的表现。

rss · IT之家 · 10月22日 07:54

**「背景」** 硅元素有硅-28、硅-29、硅-30 三种稳定同位素，其中硅-28 的原子核自旋为零，不会像硅-29 和硅-30 那样产生核自旋噪声，因此被视为硅基量子芯片最理想的衬底材料。但三种同位素的化学性质极为接近，高丰度硅-28 的分离与富集长期是材料环节最难跨越的门槛之一。今年 6 月，中核集团核工业理化工程研究院已宣布首次实现丰度超过 99.99%的硅-28 同位素自主量产，但当时打通的是同位素富集环节，向下游外延材料的转化尚未完成。

**「影响」** 国内硅基量子芯片研发在衬底材料端首次获得从特气到外延片的国产选项，但材料丰度达标仅是获得长相干时间的基础条件，器件工艺与界面缺陷控制等环节仍需验证。
