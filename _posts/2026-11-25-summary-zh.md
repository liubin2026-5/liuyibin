### [OpenAI 预印本称矩阵乘法指数为 9/4](https://github.com/openai/math/blob/main/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/paper.pdf) ⭐️ 9.0/10

OpenAI 在 GitHub 发布预印本，声称矩阵乘法的指数精确为 9/4（即Θ\(n^2.25\)），且该结果在任意域上成立。社区评论称，这一结论与“矩阵乘法指数等于 2”的猜想相矛盾，并把它列为 OpenAI 四篇新论文所解决的八个“数学前 500 开放问题”之一。评论还提到，同一批工作涉及强多项式线性规划（Smale 第九问题）、平均收益博弈和奇偶博弈等问题。上述说法目前仅来自 PDF 链接与社区讨论，尚无独立验证，因此应视为待核实的高影响力主张。

hackernews · E-Reverance · 11月25日 01:19 · [社区讨论](https://news.ycombinator.com/item?id=50637220)

**「背景」** 矩阵乘法指数ω描述的是计算两个 n×n 矩阵乘积所需的最小渐近指数，目前已知上界低于 3 但高于 2，而ω是否等于 2 长期是计算复杂性理论的核心开放问题。若ω被确定为 9/4，将直接否定ω=2 的猜想，并改变相关算法复杂度分析的理论基准。

**「影响」** 若该结果经同行验证成立，将重塑矩阵乘法及相关代数算法的复杂度上界认知，并可能影响依赖快速矩阵乘法的算法设计。

**「社区讨论」** 评论者一方面惊叹 OpenAI 与 Anthropic 近期密集产出基础性成果，将其比作贝尔实验室；另一方面质疑这些机构的动机与成果用途，担心密码学相关突破被用于攻击而非防御，并呼吁推进密码敏捷性。也有人推测 OpenAI 可能用未公开的更强模型进行内部研究，形成能力复利循环。

### [花 3 美元接管美国财政部子域名](https://www.intruder.io/research/taking-over-us-treasury-subdomains-for-3-each) ⭐️ 8.0/10

安全研究人员在 Intruder 的报告中描述了如何以每个约 3 美元的成本接管美国财政部的子域名：他们重新分配已被释放的 AWS IP 地址，并利用仍指向这些 IP 的 DNS 记录完成接管。AWS 向研究人员确认不会做出改变，认为该接管取决于客户侧的 DNS 记录，而非其服务本身的问题；AWS 还表示将快速分配和释放 IP 视为违反政策的行为，并设有相应控制措施。研究人员承认这一说法属实，但认为 AWS 本可以采取更多措施来防止该问题，并指出由于 AWS 的立场，这类漏洞仍然存在。该攻击属于“悬空云 IP 导致的子域名接管”这一可复现的攻击类别，目标为高知名度机构。

hackernews · negura · 11月25日 04:27 · [社区讨论](https://news.ycombinator.com/item?id=50638478)

**「背景」** 子域名接管通常发生在 DNS 记录仍指向某个云资源、而该资源已被释放的情况下：攻击者重新申请到同一 IP 或资源后，即可控制该子域名。由于云厂商的 IP 池会被回收再分配，客户在拆除基础设施时若未同步清理 DNS 记录，就会留下可被利用的悬空记录。

**「影响」** 使用云服务并自行管理 DNS 的组织面临实际风险：一旦释放的 IP 被他人重新分配，残留的 DNS 记录就可能让攻击者控制其子域名，并借此为该域名申请有效证书。AWS 目前将责任归于客户侧配置，因此缓解措施主要依赖组织自身的清理流程。

**「社区讨论」** 评论者普遍认为 AWS 应承担更多责任，有人建议 Route53 提供随资源删除而自动清理的 Elastic IP 记录类型，也有人质疑同一组织内重新分配被禁账户 IP 的做法属于 AWS 的疏漏。另有讨论聚焦 HTTPS 角度，认为域名验证证书的普及让此类攻击更具破坏性，并对 .gov 域名出现该问题感到震惊；实践派则强调应建立主机下线清单，在拆除时同步清理防火墙、WAF 和 DNS 记录，并定期审查 DNS。

**标签**: `#security`, `#dns`, `#cloud-infrastructure`, `#aws`, `#subdomain-takeover`

### [OpenAI 模型改写 AMD 旗舰 GPU RTL，PPA 提升约 14%](https://www.leiphone.com/category/ai/9tAw4Cw8AcxtFzUm.html) ⭐️ 8.0/10

雷锋网报道称，OpenAI 的模型直接改写了 AMD 旗舰 GPU IP 的 SystemVerilog RTL，在历经多年优化的设计基线上取得约 14% 的 PPA（性能、功耗、面积）改进，部分修改已被 AMD 纳入近期送往制造的设计，其他候选进入后续版本的生产设计文件。双方在不到五个月内完成了相当于约一年工程进展的工作量，AMD 还在下一代旗舰 CPU 的关键模块上核实了个位数百分比的 PPA 收益。OpenAI 自研推理芯片 Jalapeño 提供了另一项验证：模型重写的一款乘法器综合标准单元面积减少约 15%，延迟从两周期缩短到一周期，并已在实物硅片上验证；另一款加法器维持两周期延迟，面积同样减少约 15%。报道强调，公开数据未拆分功耗、频率和面积各自的变化，也未公布修改前后的门级网表，14% 不能等同于整颗 GPU 的成品性能增幅，送制造也不等于已有量产芯片实测结果。

**「背景」** 在芯片设计中，越接近商业量产的成熟旗舰 IP，优化边际成本越高，顶尖团队耗时数年打磨的电路在迭代后期往往连 1% 到 2% 的 PPA 提升都代价极高。传统综合工具只能在既定 RTL 下化简逻辑和做门级映射，若寄存器边界和运算资源已经写死，可探索的结构就受到约束；模型直接改写 RTL 则能重写数据通路和时序安排。但寄存器移动会改变跨周期行为，需要顺序等价验证等流程确认新电路在复位、暂停、恢复等场景下仍符合接口契约。

**「影响」** 若报道属实，这意味着 AI 模型已能对商业级 GPU 的微架构提出被制造流程采纳的结构性修改，而不仅是生成辅助代码；但 14% 是局部 PPA 改进而非整芯片性能数据，且缺乏独立验证与网表公开，实际量产收益仍待观察。

### [英伟达开放 30B MoE 生图模型权重](https://www.ithome.com/1/032/444.htm) ⭐️ 8.0/10

据 IT 之家援引科技媒体 Wccftech 11 月 25 日报道，英伟达在 Hugging Face 平台悄然公开了 Nemotron-Labs-Image-30B-A3B 模型的权重。该模型采用混合专家架构，总参数 300 亿、推理时激活 30 亿参数，是一款自回归图像生成模型，也是英伟达新框架 Nemotron-Labs-VisualCreation 的核心光栅渲染引擎，该框架以“像素即代码”为理念，可产出网页、幻灯片、文档、图表和科学插图等可编辑视觉成果。模型基于 Nemotron 3 Nano 打造，沿用 Nemotron-H 混合设计，结合 Mamba-2 状态空间层与传统注意力机制，并经过渐进式中期训练和组相对策略优化（GRPO）。跑分上，它在 LongTextBench 取得 97.98 分，高于 GPT Image 2 的 96.00 和 Nano Banana Pro 的 97.60；GenEval 以 92.86 领先 GPT Image 2 的 89.00，并在 CVTG-2K（92.53）、WISE Verified（91.50）和 BizGenEval（86.0）中拿到最高分。不过在 GenEval2 上 GPT Image 2 以 81.00 对 65.43 占优，Qwen-Image-Bench 上 GPT Image 2 也以 65.23 对 52.46 领先，OneIG 上 Nano Banana Pro 以 58.30 居首。

rss · IT之家 · 11月25日 10:37

**「背景」** 混合专家（MoE）架构通过让每次推理只激活部分参数来降低算力开销，因此 300 亿总参数、30 亿激活参数的配置对本地硬件更友好。自回归图像生成则把图像视为序列逐段生成，与扩散模型路线不同，便于与语言模型式的训练方法结合。英伟达此前已通过 Nemotron 系列开放模型权重，此次将同一思路延伸到视觉创作领域。

**「影响」** 对希望在本地或私有环境部署图像生成能力的开发者而言，这一开放权重提供了激活参数仅 30 亿的可选方案，但基准表现因测试集而异，实际可用性仍需独立验证。

### [三星计划 2027 年初出样 CXL 3.2 内存模组 MD310](https://www.ithome.com/1/032/376.htm) ⭐️ 7.0/10

三星电子 DS 部存储器业务高级副总裁심호준在 11 月 25 日的一场论坛上表示，计划 2027 年初出样 CXL 3.2 内存模组 CMM-D MD310。MD310 基于 DDR5-7200 DRAM Die，采用 EDSFF E3.S 2T 外形规格，单体容量可达 256GB，配备 CXL 3.2/PCIe Gen6 接口，可为系统额外提供 72GB/s 内存带宽，预计在获得客户认证后于 2027 年下半年量产。三星还规划了基于 LPDDR5X 的 MD320，预计 2028 年推出，在压缩技术加持下最大容量有望达到 4TB，同时能效大幅改进。CXL 内存模组通常基于 DDR，MD320 是较少见的采用 LPDRAM 的产品。
