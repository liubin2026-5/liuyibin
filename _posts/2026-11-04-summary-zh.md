### [Maxinsights 称机器人第一视角数据年化收入达 2.5 亿美元](https://www.tmtpost.com/8193146.html) ⭐️ 7.0/10

硅谷 101 对话 Maxinsights 创始人袁宇光，介绍其通过可穿戴设备采集人类第一视角视频、加工为机器人训练数据集的商业模式。创始人称公司 ARR 从去年约 100 万美元增至 2026 年预测的约 2.5 亿美元，累计近 200 万小时第一人称数据，月产能最高 45 万小时，全球约 4000 名采集员，而全职运营团队不足 10 人。这些数字均为公司单方主张，未经审计或第三方核实，且 ARR 为预测口径。

rss · 钛媒体 · 11月4日 08:59

**「背景信息」** 过去两年机器人公司普遍反映训练数据不足，行业探索遥操作、仿真、第一人称视角等多种数据来源。Maxinsights 称 2025 年首个订单为 200 小时第一人称视角数据，客户为美国头部大模型公司，此后数据量从 2 万小时增至 20 万小时。创始人认为数据痛点已从“缺数据”转向“缺高质量数据”，并称数据规模定律在具身智能领域已实现。上述行业判断与数据增长均为受访者自述，尚无独立验证。

**「内容切入角度」** 可做角度：从 Maxinsights“4000 名采集员、全职运营不足 10 人”的管理模式切入，拆解其如何用 AI Agent 平台管理分散在八个国家的采集团队，对比外包与自营在数据质量、反馈速度上的差异，讨论众包数据采集在规模化与质量控制之间的张力。

**「商业价值」** 对数据要素流通和数商创业者而言，该案例展示了将人类日常动作视频加工为机器人训练数据商品的具体路径，涉及硬件设计、采集运营、数据处理管线和质量分级等环节。对电商卖家或互联网创业者，其“以设备为中心”的运营思路和 AI Agent 管理分散团队的方式，在众包履约场景中有一定参考价值，但核心数字来自创始人自述，不宜直接作为市场判断依据。

### [《PostgreSQL 内部原理》在线书再获关注](https://www.interdb.jp/pg/index.html) ⭐️ 8.0/10

《The Internals of PostgreSQL》是一本详细讲解 PostgreSQL 内部架构的在线书籍，近日再次出现在 Hacker News 上并引发讨论。该书覆盖 MVCC、HOT 更新、TOAST 以及 SSI 等核心机制，被从业者视为数据库内核工作的重要参考资料。此次讨论中，有评论者建议读者优先阅读 HOT 更新路径，并结合 zHeap 实现说明与 TOAST 内容建立对 PostgreSQL 行为边界的整体认知。也有评论指出书中未涵盖较新的 MVCC 实现，并提及 OrioleDB 等替代方案。

hackernews · ibobev · 11月3日 21:51 · [社区讨论](https://news.ycombinator.com/item?id=50358702)

**「背景」** PostgreSQL 采用多版本并发控制（MVCC）来支持并发读写，HOT（Heap-Only Tuples）更新用于减少索引维护开销，TOAST 负责存储超大字段值，SSI（可串行化快照隔离）则提供可串行化隔离级别。理解这些机制对数据库内核开发、性能调优和故障排查都很关键，而系统性的内部原理资料相对稀缺。

**「影响」** 对从事 PostgreSQL 内核开发、性能调优或存储引擎研究的开发者而言，该书仍是理解 MVCC、HOT 与 TOAST 等机制的高价值入门与参考材料。

**「社区讨论」** 评论者普遍认可该书的技术深度，有人回忆 2018 年在 Greenplum 团队结合 CMU 数据库课程共同研读此书，称其对内核工作极有价值。讨论中也出现分歧：有评论指出书中缺少较新的 MVCC 实现，并推荐关注 OrioleDB；另有评论提到近期 Jepsen 关于 particledb 的报告重新引发了对 PostgreSQL SSI 实现的兴趣。

### [C++26 标准提案未获通过 契约机制争议成焦点](https://andreasfertig.com/blog/2026/11/cpp26-dis-failed-how-does-cpp-survive/) ⭐️ 8.0/10

一篇博客文章与 Hacker News 上的讨论聚焦 C++26 未获批准一事，核心争议在于 C++ Contracts（契约）提案以及 ISO 标准化流程本身。讨论中，有开发者质疑契约机制是否解决了真实代码库中的实际问题，认为在 C++20 concepts 之后其收益难以量化。也有观点指出，可在分析阶段由静态分析器、模型检查器或定理证明器验证的契约注解极具价值。另有评论借 Rust 是否寻求 ISO 认证的旧争论，质疑 ISO 流程带来的官僚负担。部分开发者则希望 C++ 放缓新特性引入，先处理 char8\_t 和 std::filesystem 等既有问题。

hackernews · thatxliner · 11月4日 00:33 · [社区讨论](https://news.ycombinator.com/item?id=50360164)

**「背景」** C++ 标准由 ISO C++ 委员会推进，按三年周期发布新版本，C++26 是当前规划中的下一个主要版本。Contracts 旨在为函数前置条件、后置条件和不变量提供语言级注解，但具体设计方向长期存在分歧。ISO 认证流程的繁琐程度此前也曾在 Rust 社区引发讨论。

**「影响」** 若 C++26 的批准受阻，依赖新标准特性的编译器厂商和库作者可能需要推迟或调整实现计划，而契约机制的未来形态仍待委员会进一步决定。

**「社区讨论」** 评论者对契约机制的实际价值看法不一：有人认其实用性存疑，有人强调其对形式化验证的意义；同时不少人对 C++ 特性持续膨胀和 ISO 流程效率表示担忧。

一个 GitHub issue 和 Hacker News 上的大量讨论指控 Postman 静默自动安装 AI 插件，并试图共享 API 数据，促使开发者重新考虑是否继续使用该工具。社区评论进一步声称，Postman 会记录每次 API 请求的详细信息，包括查询参数；即使用模板语法 \{\{some\_secret\}\} 填充参数，实际密钥内容也会被发送到 Postman 服务器，而禁用该日志端点的出站流量会导致应用无法正常工作。有医疗行业用户表示，其网络安全团队因此将 Postman 取消认证，团队一夜之间全部切换到 Bruno。上述指控主要来自 GitHub issue 和社区经验，尚未经过独立验证。

hackernews · sidgarimella · 11月3日 17:22 · [社区讨论](https://news.ycombinator.com/item?id=50354960)

**「背景」** Postman 最初是一款轻量的 API 测试工具，后来发展为包含登录、订阅和 AI 功能的商业化平台。API 测试工具通常需要处理请求参数和密钥，因此其遥测和数据收集行为对隐私敏感行业尤为关键。Bruno 等替代工具主打本地存储和将请求定义纳入 Git 管理。

**「影响」** 对隐私敏感行业（如医疗）的开发者而言，这些指控可能直接导致内部安全团队取消 Postman 的认证并推动迁移到 Bruno 等替代工具。

**「社区讨论」** 评论普遍对 Postman 的膨胀、强制登录和数据收集表示不满，多位用户称已迁移到 Bruno，并看重其将请求定义存入 Git 的能力。也有用户质疑 Postman 的高估值与庞大团队，认为其商业模式与开发者工具定位存在冲突。

德国初创公司 Orbital Matter 的 Replicator 2 小型卫星在自由飞行状态下，利用 4 台 3D 打印机中的部分设备，通过挤出树脂线圈并用紫外线固化，制造出一根长约半米的圆柱形刚性横梁。公司称这是自由飞行航天器首次在轨完成此类打印，也是未来在太空建造大型结构的重要一步。该卫星于今年夏季搭乘 SpaceX 拼车发射任务入轨。打印长度受卫星携带树脂量限制，但工程师认为制造 100 米长横梁可行。任务中一台打印机发生故障，另一台成功制造支撑杆并展开柔性太阳能电池阵列，构成概念验证。

### [Anthropic 开发 FlashProve：密码学验证 AI 输出来源](https://www.ithome.com/1/022/231.htm) ⭐️ 8.0/10

Anthropic 正在开发名为 FlashProve 的开源系统，旨在通过密码学证明实现“可证明推理”，为特定 AI 输出提供数学层面的保证，证明其确实来自某个指定模型。该系统工作原理类似加密电子邮件签名，能够抵御将一个模型伪装成另一个模型的行为，即使实施伪装的正是开发并运行该模型的 AI 公司也难以绕过验证。AI 实验室需为发布的每个模型提供“指纹”，指纹不会泄露模型权重，因此可适用于商业闭源模型。系统设计力求轻量化，用户可直接在本地设备上完成验证。Anthropic 已公布详细技术规范及系统各组件的可运行代码，代码在 GitHub 上以开源许可证公开，但相关研究仍在进行中，尚未计划在自家或其他 AI 实验室部署。

rss · IT之家 · 11月4日 08:04

**「背景说明」** 在 AI 服务中，用户通常只能依赖服务提供方的声明来判断自己使用的是哪个模型，缺乏独立验证手段。模型权重是决定模型行为的内部参数，Anthropic、OpenAI 等闭源开发商通常将其作为商业机密保护，这使公开验证与商业保密之间存在天然张力。FlashProve 试图在不暴露权重的前提下提供来源证明，从而填补这一信任缺口。

**「潜在影响」** 若该系统最终落地，用户和企业将能独立核验 AI 输出是否来自声称的模型，从而抑制暗中换用更便宜模型削减成本、或换用更昂贵模型人为抬高测试结果等行为。不过目前研究仍处于阶段性进展，尚无部署计划，实际效果有待验证。

### [小鹏联合北大港大发布 GroundingPI 感知基座模型](https://www.ithome.com/1/022/289.htm) ⭐️ 7.0/10

小鹏集团联合北京大学、香港大学等高校研究团队发布具身感知基座模型 GroundingPI，采用“感知优先”技术路线，参数规模约 40 亿。官方称该模型在 34 项公开感知基准的综合评测中位列第一，按 11 类能力等权平均得分为 73.68，高于 OpenAI 前沿模型 GPT-6 Astra 的 71.54。训练阶段不使用带关节动作标签的机器人数据，全部采用覆盖通用检测、密集小目标、指代定位、文字识别、文档版面、界面元素、机器人空间定位等 11 类能力的纯感知数据，目标是让模型先理解“物体是什么、在画面哪个位置”。官方表示研究目前处于科研原型阶段，仿真结果显示以 GroundingPI 为视觉底座的系统仅用 50%示教数据即超过对比模型使用 75%数据的成功率，并在材质、品类、容器、背景变化下保持较强泛化性。

rss · IT之家 · 11月4日 09:40

**「背景」** 具身智能通常指能在物理环境中感知并行动的智能系统，主流 VLA（视觉-语言-动作）模型往往同时学习“物体在哪”和“如何动作”。GroundingPI 的名称中 Grounding 对应视觉定位能力，PI 为 Physical Intelligence（物理智能）的缩写，其思路是把空间定位等感知表征从动作学习中剥离出来单独预训练。

**「影响」** 若结论成立，机器人部署方有望以更少的人工示教数据达到同等任务成功率，并让同一套权重跨工位复用；但当前证据仅来自厂商发布，论文与代码虽已给出链接，尚缺独立复现验证。

**标签**: `#embodied AI`, `#foundation models`, `#robotics`, `#benchmarks`, `#computer vision`

### [京东五年拟采购 300 万台机器人、100 万台无人车](https://www.ithome.com/1/022/267.htm) ⭐️ 7.0/10

在 2026 年世界互联网大会乌镇峰会机器人与具身智能论坛上，京东集团技术委员会主席曹鹏宣布，未来五年京东物流计划采购 300 万台机器人、100 万台无人车和 10 万架无人机，推动 AI 与机器人融入供应链全流程。京东同时启动“京东物理 AI 加速计划”，第一阶段聚焦具身智能机器人，在数据、基地、制造、销售、物流和服务六个方向持续投入。数据方面，京东具身数采已覆盖 100 余个细分生产服务场景、采集超 10 万真实作业任务，并计划两年内累计采集超 1000 万小时人类真实场景视频数据和超 100 万小时机器人本体运行数据。京东称其 AI 已应用于零售、物流、健康、工业等超过 3000 个场景，并拥有 3800 多个仓库及超 20 万家合作线下零售药房等场景资源。上述采购与采集目标均为面向未来的规划性指标，尚未披露具体落地节奏与验证结果。

**「背景」** 具身智能指将 AI 能力嵌入机器人等物理实体，使其能在真实环境中感知、决策和操作，其训练高度依赖真实作业数据。京东物流长期推进仓储与配送自动化，此次计划将机器人从单点操作推向流程协同，智元具身机器人已进入京东物流智狼仓进行真实作业检验。

**「影响」** 若计划推进，京东物流将成为大规模具身智能机器人采购方，为机器人厂商提供规模化订单与真实场景验证机会，同时其数据采集规模也可能影响行业具身数据供给。

### [笔记本上的 Qwen 3.8 27B 也能“读懂”模型权重](https://simonwillison.net/2026/Nov/3/qwen-can-interpret-model-weights/) ⭐️ 6.0/10

Simon Willison 在个人博客中称，他在笔记本上运行的 Qwen 3.8 27B（17GB 的 GGUF 版本，经 LM Studio 加载）复现了“Weight-Space Programming”论文中的一个示例：仅凭一段包含浮点数的权重文本，判断该网络训练时玩的是哪款游戏。他测试了 Pac-Man 提示，模型在 46 分 12 秒、43,506 个推理 token 后给出“简化 Pac-Man 风格网格世界”的判断，自评置信度 72%；他还称另外两款游戏也识别成功，但原文摘录在此处截断。作为对照，Kimi K3.1 Pro 在 9 分 41 秒、19,493 个推理 token 后猜对了 Breakout。

rss · Simon Willison · 11月3日 16:29

**「为何值得注意」** 该实验呼应了近日引发讨论的论文，其摘要称 GPT-6 Astra 能仅凭原始权重判断网络用途，并通过原生编辑 0.016% 的权重把 Qwen3.5-0.8B 的 MATH-500 从 7.9% 提升到 48.1%。不过该论文被作者自己归类为“博客文章”，且 Matthew Honnibal 批评其混淆了“无工具读权重”与“借助代码改权重”两件事，Sean Goedecke 也拆解了其中的权重修改案例。Willison 的复现只针对无工具识别游戏这一子问题，尚不能说明本地模型具备论文宣称的完整能力。

**「可做角度」** 可做角度：把“模型能否只看权重就说出网络在做什么”当作一个可亲手验证的小实验来写——交代提示词来自论文仓库、四个游戏提示除权重外完全相同、本地运行需要调大上下文与超时，并如实呈现耗时、token 数与置信度，同时说明这只是单次复现，不构成对论文整体结论的背书。
