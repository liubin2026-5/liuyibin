### [新疆 450 公里无人机货运航线首投双 11 大促](https://www.cyzone.cn/article/853743.html) ⭐️ 7.0/10

11 月 9 日，一家快递物流企业在新疆开通连接阿克苏地区与叶城的大型无人机货运航线，直线航程约 450 公里，最大商载 1.9 吨，单程飞行约 2.5 小时，货物可实现次日送达。这是无人机支线运输首次投入“双 11”大促。此前两地货物依赖公路并绕行乌鲁木齐集散，全程陆运约 2730 公里，收件到送达通常需三到四天。

rss · 创业邦 · 11月12日 03:53

**「背景与不确定性」** 该航线替代的是卡车在长距离、低密度线路上的支线货运角色，而非末端配送。其稳定运行取决于起降场地、空域排期审批、恶劣天气备降方案及货物保险安排等条件。大促期间为临时加开，能否转为全年常态化，仍要看单班装载率、机组与维护成本能否摊薄。材料未点名具体企业，所引全国注册无人机 328.7 万架、低空经济企业超 10.7 万家等数据未注明官方出处。

**「内容切入角度」** 可做角度：从“绕行成本”切入，对比新疆两地此前 2730 公里陆运绕行与 450 公里直线航线的时效差异，讨论无人机支线货运在大促临时加开与全年常态化之间还差哪些条件（装载率、空域审批、备降与保险）。

**「对从业者的意义」** 对电商卖家而言，支线无人机若稳定运行，生鲜、药品等时效敏感品类进入更远市场的时间窗口从三四天压缩至次日；但当前仅为大促临时航线，常态化仍取决于装载率与成本，不宜据此调整长期物流规划。

### [Apache HTTP Server mod\_http2 曝严重 RCE 漏洞](https://www.wiz.io/blog/cve-2026-119618-rce-apache-http-server-vulnerability) ⭐️ 8.0/10

据 Wiz 博客报道，Apache HTTP Server 的 mod\_http2 模块存在一个严重远程代码执行漏洞，相关补丁提交已公开。该漏洞影响广泛部署的 Web 服务器基础设施，因此需要尽快关注。社区讨论指出，使用 mpm\_prefork 的 Apache/PHP 部署可能不受影响，这为实际暴露面提供了缓解线索。同时，报道中出现的 CVE 编号存在不一致（CVE-2026-111497 与 CVE-2026-119618），使漏洞标识的确定性有所降低。

hackernews · soheilpro · 11月12日 02:11 · [社区讨论](https://news.ycombinator.com/item?id=50462177)

**「背景」** mod\_http2 是 Apache HTTP Server 中实现 HTTP/2 协议的模块。HTTP/2 旨在提升性能，但引入了多路复用、流控制等额外复杂度，历史上也曾出现安全缺陷。Apache HTTP Server 长期是主流 Web 服务器之一，其模块漏洞通常影响面较大。

**「影响」** 运行启用 mod\_http2 的 Apache HTTP Server 的用户可能面临远程代码执行风险，应优先核查并应用补丁；而使用 mpm\_prefork 的部署可能不受影响，但仍需以官方公告为准。

**「社区讨论」** 有评论认为 HTTP/2 的复杂度不值得其理论收益，并质疑其被快速推进；也有资深管理员表示已多年未接触 Apache，以为 nginx 等方案已占主导。另有评论指出多数 Apache/PHP 安装使用 mpm\_prefork 因而可能不受影响，并有人注意到报道中两个 CVE 编号不一致的问题。

**标签**: `#security`, `#apache-http-server`, `#http2`, `#vulnerability`, `#open-source`

### [长鑫 DDR5 进展：32Gb 颗粒与 12800Mbps MRDIMM](https://www.ithome.com/1/026/241.htm) ⭐️ 7.0/10

长鑫科技披露了其 DDR5 RDIMM 与 MRDIMM 产品线的最新进展：DDR5 颗粒已完成从 24Gb 到 32Gb 的迭代，RDIMM 模组覆盖 32GB 至 128GB 主流容量以及 5600Mbps 至 8000Mbps 速率区间，MRDIMM 则提供 128GB 和 192GB 容量、最高速率可达 12800Mbps。MRDIMM 通过 MRCD 与 MDB 元件同时访问多个内存列以提升带宽，并采用标准 287-pin 设计兼容 DDR5 RDIMM 插槽，无需改动系统架构即可升级，主要面向 AI 大模型训练与推理、高性能计算等场景。长鑫科技副总裁骆晓东表示，内存需求进入“分层时代”，服务器市场需求占比已超过 50%。公司还称，受 AI 应用驱动，四季度服务器客户需求依然强劲，DRAM 供不应求态势将延续，预计四季度营收继续增长。上述产品进展与市场判断均来自厂商方面，属于企业自述信息。

rss · IT之家 · 11月12日 09:01

**「背景」** 24Gb、32Gb 指单颗 DRAM 颗粒的容量，单位为吉比特，32Gb 约合 4GB；颗粒容量越大，相同模组容量下所需堆叠的颗粒数量越少。RDIMM 是面向服务器和数据中心的寄存式内存模组，通过内置寄存器缓冲控制信号以稳定系统并支持更大容量；MRDIMM 是面向 AI 与高性能计算的新一代高带宽内存，在单个模组内使用多个内存列，借助 MRCD 和 MDB 元件并行访问以提升带宽并降低内存控制器负载。

**「影响」** 若这些产品按所述规格落地，现有 DDR5 RDIMM 服务器平台可凭借 287-pin 兼容性直接采用更高带宽的 MRDIMM，为 AI 训练推理与高性能计算提供无需重构系统架构的升级路径。
